JUNAF / WEB APP

安装 JUNAF

从电脑的程序坞或手机的主屏幕打开 JUNAF，进入音乐、影像、思考和工具。

选择你的设备

01 / DESKTOP

电脑

Chrome 或 Edge 使用地址栏的安装图标，或从浏览器菜单选择安装 JUNAF。

Mac 上的 Safari 选择「文件」→「添加到程序坞」。

02 / iOS & iPadOS

iPhone 或 iPad

用 Safari 打开此页，点「分享」→「添加到主屏幕」。如果看到「作为网页 App 打开」，请开启，然后点「添加」。

03 / ANDROID

Android

用 Chrome 打开此页，点击「安装 JUNAF」，或在浏览器菜单选择「安装应用」或「添加到主屏幕」。
