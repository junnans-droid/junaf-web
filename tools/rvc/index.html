训练自己的音色，
让声音继续发生。

第一次使用，从上传自己的干净人声录音开始。完成训练后，就可以选择这个音色，上传另一段音频进行转换。还没有训练好的音色时，模型列表保持为空。

返回工具目录

当前仅管理员账号可用。4090 无卡模式可以查看工作台和上传录音；训练、特征提取与转换需要有卡开机。

01 / 准备

上传自己的录音

准备只有一个人声、尽量没有背景音乐和混响的录音。在“训练我的音色”页多选上传，点击“保存训练录音”；录音位置会自动填写。

02 / 训练

一键训练我的音色

确认录音位置已自动填好，点击“开始训练我的音色”。工作台会自动处理数据、提取特征、训练模型并建立索引；旁边的分步按钮供进阶排查使用。训练需要 4090 有卡开机。

03 / 使用

用自己的音色转换

训练完成后，打开“音频转换”，点击“刷新我的音色”，选择模型、上传待转换音频，然后试听或下载结果。RVC 与 YuE2 共用 4090，请错开大任务。

音色归属由你训练 · 由你管理

工作台不会预选其他人的示范音色。请只上传你有权使用的录音；训练数据与生成的模型保存在 4090 实例的数据盘。
