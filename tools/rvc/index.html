用自己的录音训练音色，或用已准备的音色转换一段声音。训练与转换在 JUNAF 的 GPU 实例中完成。

返回工具目录

工作台当前仅管理员账号可用。请先登录 JUNAF。

01 / TRAIN

训练自己的音色

准备有权使用的干净人声录音，在工作台的训练页多选上传。路径会自动填入，再完成预处理、特征提取、训练和索引生成。

02 / CONVERT

转换一段声音

选择音色模型，上传音频，调整音高与索引比例，试听并保存转换结果。首次可选择已安装的示范音色。

03 / PRIVATE

按需使用 GPU

AutoDL 实例开机后工作台可用；关闭实例可停止计费。RVC 与 YuE2 共用一张 GPU，请错开大任务。
