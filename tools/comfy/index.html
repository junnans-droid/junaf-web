01 / 输入THE STARTING FRAME

输入方式：参考图＋提示词。模型没有固定题材，按你的描述生成。

选择一张图，作为视频的起始画面

模板1：参考图 → 局部往复运动 → 30fps慢放与端点缓动 → 正倒放拼接。正向5秒得到约10秒循环，正向10秒得到约20秒循环。可更换烟雾、粒子等参考图。

查看模板追加的运动规则

首尾画面约束不保证运动无缝。循环候选需重复播放验收，原始结果会保留。

尾帧续接：以上一段视频的最后一帧作为下一段首帧，同时自动沿用原提示词和画面尺寸。可点击“复制提示词”保存或复用。保持相同提示词有助于一致性；画面差异只作提示，不会自动重试或丢弃结果，请预览确认。

输出修正 · 可选

防抖处理整体位移和轻微旋转；固定色调减轻整体偏色，不锁定亮度或局部材质。不能修复主体变形、纹理跳动。处理前视频会保留。

每次只处理一个任务。续接自动沿用原提示词、画面尺寸与上一段尾帧；完成后请预览确认风格和运动。
